# 장애 안내 음성

실제 통화 녹음이 아닌, 이 프로토타입을 위해 로컬 음성 합성으로 만든 일반 안내입니다. 개인정보·예약 이름·전화번호를 포함하지 않습니다. TTS 공급자가 응답하지 않아도 PCM 프레임으로 재생합니다. 전화 미디어 경로 자체가 끊긴 경우에는 전달을 보장하지 않습니다.

| 파일 | 정확한 문구 |
| --- | --- |
| call_end.wav | 이번 통화는 여기서 마치겠습니다. 예약 결과는 서비스에서 확인해 주세요. |
| please_repeat.wav | 말씀을 처리하지 못했어요. 다시 한 번 말씀해 주시겠어요? |

2026-11-10 macOS 내장 `say`, Yuna, 속도 165로 생성했습니다. 형식은 mono PCM16, 16 kHz WAVE입니다. 런타임·Linux CI에는 macOS 음성 합성이 필요하지 않습니다. 이 음성은 통화의 성공/실패를 임의로 선언하지 않으며, 예약 상태는 저장된 결과가 기준입니다.

재생 문구를 바꾸면 해당 WAV와 `resilience.py`의 텍스트를 함께 갱신하고 청취를 확인합니다. 외부 TTS를 새로 호출하거나 실제 통화를 녹음한 파일로 교체하지 않습니다.
