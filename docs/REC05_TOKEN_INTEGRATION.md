# REC-05 인증 PR 연동 검토와 개발용 호출자

확인일: 2026-11-08 KST. 담당: `tiemo0708`, 이슈 #16, Draft PR #19. #19의 독립 HTTP 초안과 [PR #21](https://github.com/arriveon-lab/pleos-reservation-assistant/pull/21)의 인증·소유권 구현을 함께 검토했습니다.

## 최근 PR에서 확인한 변경

새로 열린 다른 팀원 PR은 #21이며 검토한 head는 `8484a0469a1aed2a1661dbbd55b7bcd6c73139bf`입니다. 서버가 앱 설치별 익명 주체와 접근/갱신 토큰을 발급하고, 유효한 Bearer 토큰을 Servlet Principal로 변환합니다. 토큰 필터 순서는 `LOWEST_PRECEDENCE - 20`, 미리보기 guard는 `-10`이며 같은 subject 형식을 사용합니다. 갱신해도 subject를 유지하므로 기존 previewId의 소유권을 이어갈 수 있습니다.

#21은 미병합이고 기존 main에는 인증 구현이 없습니다. 검토 시 원격 Verify 두 검사는 Gradle 배포본 다운로드의 HTTP 504/타임아웃으로 테스트 실행 전에 실패했습니다. 이는 코드 테스트 실패와 구분하며 원격 검증 성공으로 취급하지 않습니다. 이 작업에서 #21을 수정·승인·재실행·병합하거나 main에 인증 소스를 넣지 않았습니다.

#21은 첫 배포 전 `/api/v1` 유지·계약 1.1.0으로 변경한 안입니다. #19 단독의 계약은 여전히 1.0.0입니다. 미리보기 기본 비활성 테스트가 문서의 계약 버전과 실제 status 응답을 대조하도록 바꿔, 고정 문자열 때문에 임시 통합본에서 실패하는 문제를 해결했습니다. v1 경로/스키마를 이번 브랜치에서 임의로 변경하지 않았습니다.

## 추가한 호출자

[preview-session-demo.py](../scripts/preview-session-demo.py)는 **#21과 #19가 함께 있는 loopback MOCK 서버**에 사용하는 일회성 개발용 호출자입니다. Android의 토큰 저장소나 운영 인증 클라이언트가 아닙니다.

1. `/api/v1/status`에서 계약 1.1.0·MOCK·가상 fixture·외부 호출 꺼짐을 확인합니다. 현재 1.0.0 서버에서는 `AUTH_INTEGRATION_REQUIRED`로 중단하며 인증 세션을 만들지 않습니다.
2. 서버에서 익명 접근/갱신 토큰을 발급받고 미리보기를 생성합니다. 사용자 ID·역할·가짜 Principal 헤더를 만들지 않습니다.
3. generation 1의 가상 식당 검색을 **한 번만** 실행합니다. MOCK 출처·모의 예약·UNKNOWN 조건·예약 불가 상태를 확인합니다.
4. 명시적인 프로토콜 검증 단계로 토큰을 한 번 갱신하고, 새 토큰으로 같은 미리보기의 generation 2를 취소해 subject 연속성을 확인합니다. 새 generation의 검색은 실행하지 않습니다.
5. finally에서 미리보기를 종료하고 인증 세션 전체를 폐기합니다. 각 정리 요청도 한 번만 시도하며 미확인은 성공으로 보고하지 않습니다.

토큰은 메모리와 HTTP 인증 헤더/갱신 본문에만 사용합니다. 명령행·출력·파일에 기록하지 않습니다. 출력에는 상태·표시 수·요청 수·정리 확인 여부만 포함하고 상호·주소·ID·subject도 출력하지 않습니다. proxy/redirect를 사용하지 않으며 대상은 `http://127.0.0.1:port`로 제한합니다.

실패 시 자동 토큰 재발급·조회 재시도·refresh-and-replay를 하지 않습니다. 갱신 키는 새 요청에 한 번 생성하고 자동 재시도를 구현하지 않았습니다. 실제 앱의 응답 유실 복구는 #21의 동일 갱신 토큰+동일 키·120초 범위와 맞춰 별도로 구현해야 합니다. 네트워크가 끊기면 정리 완료를 보장할 수 없으며 새 익명 주체로 기존 데이터를 자동 복구하지 않습니다.

```bash
# #21 + #19 통합 검증 서버를 --app.place-preview.enabled=true로 실행한 경우에만 성공
python3 scripts/preview-session-demo.py --base-url http://127.0.0.1:8080

# 외부 네트워크/실제 토큰 없이 호출자 실패·정리 동작 검증
python3 -m unittest discover -s scripts/tests -p test_preview_session_demo.py
```

임시 통합 시 STATUS·인계·smoke-test.py에서 충돌이 발생했습니다. 문서는 양쪽 이력을 보존하고, smoke는 #21의 실제 토큰/소유권·테스트 운영자 흐름과 #19의 스키마/404/401 검증을 함께 실행했습니다. 추가로 #21의 `preview-token-smoke.py`와 이번 호출자를 opt-in JAR에 실행했습니다. 필터·인증·업무 소스는 별도로 고치지 않고 연동됐습니다. 임시 통합본은 push/병합하지 않습니다.

로그·집계 메타데이터는 로컬 Git 제외 work/에 보관합니다. 인증 토큰 원문/응답·개인 정보·실제 장소 응답은 공개 산출물에 넣지 않습니다. 새 호출자 unittest를 Server and contract CI에도 연결했습니다. Android 기기 실행·실제 외부 장소/전화/예약/유료 작업은 수행하지 않았습니다.
