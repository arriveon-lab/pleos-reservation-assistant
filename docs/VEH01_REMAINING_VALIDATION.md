## 서버의 기존 시간 경계 예제 — 실제 HTTP 호출 결과 아님

가상 now=`2026-11-11T03:00:00Z`, 필수 필드와 형식이 올바른 기존 MOCK/MANUAL Navigation을 전제로 한 시간 검사 표입니다. 인증/소유권·전체 요청 검증까지 성공한다는 뜻이 아닙니다.
