# 팀원용 Pleos 전화 시연 촬영 가이드

Pleos 앱에서 추천을 받고 본인 휴대폰으로 시험 예약 전화를 받습니다. 촬영자는 앱에서 운전자 역할을, 휴대폰에서는 식당 직원 역할을 맡습니다. 차량 화면은 정차한 Pleos Connect 에뮬레이터에서 촬영합니다. 예약을 확정한 뒤 교통 지연 변경 전화와 식당발 070 회신을 이어서 찍을 수 있습니다.

## 1. 앱과 휴대폰 준비

- `main`의 [PR #71 반영 커밋](https://github.com/arriveon-lab/pleos-reservation-assistant/commit/2343176db5d099bb05f719756cb26030c1afcf15) 이후 소스로 LIVE 시험 APK를 빌드하거나, 팀에서 받은 동일 버전의 APK를 설치합니다. SDK와 Pleos 에뮬레이터는 [Android 환경 설정](ANDROID_SETUP.md)을 따릅니다.
- 국내 010 휴대폰을 준비합니다. 통화 음성도 영상에 담으려면 녹화 PC의 마이크가 휴대폰 스피커 소리를 받는지 미리 확인합니다.
- **070 회신 장면을 찍을 경우** 팀에서 사용하는 시험용 070 번호를 확인합니다. 아래 Swagger에서 `LIVE`로 연결하면 본인 번호가 발신과 회신에 함께 등록됩니다.
- 실제 검색과 통화에는 비용이 발생할 수 있습니다. 촬영 전에 시험 범위를 운영자와 맞추고, 화면 녹화는 번호 등록을 마친 뒤 시작합니다. 연결 코드, 로그인 정보, 휴대폰 전체 번호가 영상에 나오면 가립니다.

직접 빌드한다면 저장소 루트에서 실행합니다. Windows PowerShell에서는 `./gradlew` 대신 `.\gradlew.bat`를 사용하고 빌드 명령을 한 줄로 입력합니다.

```bash
./gradlew -PincludeAndroid=true -PnavigationDemo=true -PrealPlaceDemo=true \
  -PpairedPhoneDemo=true :android:app:assembleDebug
adb devices
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

ADB에 기기가 여러 개 보이면 `adb -s <serial> install -r …`로 Pleos 에뮬레이터를 지정합니다. 서명이 일치하지 않는다고 나오면 기존 앱을 지우기 전에 팀 APK와 서명을 확인합니다. 기본 예약자 이름은 **가상 시험자**입니다. 이름을 바꿔야 할 때만 빌드 명령에 `-PliveTestReservationName=김예약`을 추가합니다. 휴대폰 번호는 다음 단계에서 연결합니다.

서명된 제출용 LIVE APK는 앱에서 번호를 직접 등록합니다. 패키지는 `ai.pleos.assistant.pairedphone.release`입니다. 설치와 등록은 [심사용 LIVE release](PLEOS_PAIRED_PHONE_TEST.md#심사용-live-release)를 따릅니다.

## 2. 내 번호를 앱에 연결

1. ArriveOn을 열고 **체험 연결 시작 → 연결 코드 발급**을 누릅니다. 앱에 표시된 10자리 코드는 5분 동안 한 번 사용할 수 있습니다.
2. [전화 시험 Swagger](https://43.201.115.170/phone-test/docs/)에서 **Pleos 앱 시험 번호 연결 → Try it out**을 엽니다. 운영자 로그인 권한이 있으면 직접 등록하고, 권한이 없으면 코드와 본인 번호를 운영자에게 비공개로 보내 등록을 부탁합니다.
3. `pairingCode`에 앱의 연결 코드, `testPhoneNumber`에 본인 010 번호를 넣고, `mode`를 **`LIVE`**로 지정한 뒤 **Execute**를 누릅니다. 응답이 `200`, `active: true`, `mode: LIVE`인지 확인합니다.
4. 앱에서 **서버 상태 다시 확인**을 누르고 `LIVE`와 내 번호 끝 네 자리를 확인합니다. 연결은 1시간 동안 유효하며 앱 연결당 검색과 발신은 각각 3회까지 가능합니다. 통화당 최대 2분입니다.

## 3. 추천과 시험 예약 촬영

1. Pleos 내비에서 **판교역**처럼 공개된 목적지로 길안내를 시작합니다. ArriveOn에서 목적지 이름을 대조하고 **이 목적지로 시연 검색 허용**을 누릅니다.
2. 인원과 필수 조건을 고르고 **주변 식당 찾기**를 누릅니다. 촬영에는 실제 반환된 후보를 사용합니다. 예시는 성인 2명, 어린이 1명, 주차와 유아의자입니다.
3. 식당 하나를 선택하고 승인 화면의 예약자 이름, 날짜, 시각, 인원, 등록 번호 끝 네 자리를 보여줍니다. 날짜와 시각은 화면 값을 사용합니다. **등록 번호 전화 시험 승인**을 누르면 본인 휴대폰이 울립니다.
4. 전화를 받아 실제 식당 직원처럼 질문별로 답합니다. 주차를 물으면 “네, 주차 가능합니다”, 유아의자는 “네, 한 개 준비할 수 있습니다”, 추가 비용은 “추가 비용은 없습니다”라고 답하는 식입니다. 마지막 예약 요청에는 “네, 가상 시험자 이름으로 예약 확정됐습니다”라고 말합니다. APK에서 이름을 바꿨다면 화면의 이름을 사용합니다.
5. 통화를 마치고 Pleos에서 **예약 확정 응답을 받았어요**와 확정 시각을 함께 보여줍니다.

## 4. 교통 지연으로 먼저 전화하는 장면

1. 확정 결과에서 **개발 도구 → 교통 지연 시연 시작**을 누릅니다. 약 4초 뒤 가상 도착 시각과 새 예약 시각이 팝업에 표시됩니다. 예를 들어 기존 예약이 19:10이면 19:30 변경을 제안합니다.
2. **19:30 변경 전화**처럼 화면에 표시된 새 시각의 발신 버튼을 누릅니다. 같은 휴대폰으로 오는 전화를 받고, AI가 기존 조건 그대로 추가 비용 없이 새 시각으로 바꿔 달라고 하면 “네, 변경 확정됐습니다”라고 답합니다.
3. 앱에서 확정 시각이 바뀌는 장면을 찍습니다. 가능 여부만 답해서 AI가 다시 물으면 변경을 완료했다고 명확히 답합니다.

## 5. 식당이 070으로 회신하는 장면

1. **앱에 `LIVE`로 등록하고 시험 예약을 확정한 동일한 010 휴대폰**에서 등록이 유효한 1시간 안에 시험용 070으로 직접 전화합니다. 앱 화면을 열어 둡니다. 일치하는 예약이 한 건이면 AI가 예약자 이름을 넣어 인사합니다. 예약을 물으면 화면에 표시된 예약자 이름, 날짜, 기존 확정 시각을 알려줍니다.
2. 식당 직원 역할로 “예약을 오늘 저녁 7시 40분으로 미뤄 주실 수 있을까요?”라고 말합니다. 앞 단계에서 새로 확정된 시각을 확인하고, 그와 다른 같은 날 시각을 제안합니다.
3. **식당에서 시간 변경을 요청했어요** 팝업에 기존 시각과 제안 시각이 표시됩니다. 통화 중 약 20초 안에 **새 시간 수락** 또는 **변경 거절**을 누릅니다. 수락 장면에서는 AI가 다시 묻고 나면 “네, 변경 확정됐습니다”라고 답합니다.
4. 수락을 찍었다면 앱의 새 확정 시각을, 거절을 찍었다면 거절 결과와 기존 시각을 보여줍니다. 수락과 거절을 모두 촬영하려면 각각 회신합니다.

## 다시 찍거나 연결이 안 될 때

| 증상 | 확인할 항목 |
| --- | --- |
| 코드가 만료됐거나 `MOCK`으로 연결됨 | 앱에서 코드를 다시 발급합니다. 이미 `MOCK`으로 등록했으면 **가상 연결 해제 · LIVE 재등록 준비**를 사용합니다. |
| 앱에 목적지가 안 보임 | Pleos 내비에서 길안내 중인지 확인하고, 앱에 목적지가 나타난 뒤 검색을 시작합니다. |
| 휴대폰에 발신 전화가 안 옴 | 앱에서 `LIVE`와 번호 끝 네 자리를 확인합니다. 휴대폰의 부재중 전화·스팸 차단도 확인하고, 앱의 통화 결과를 먼저 확인합니다. |
| 070 회신이 연결되지 않음 | 앱에 `LIVE`, 내 번호 끝 네 자리, 확정 예약이 표시되는지 확인합니다. 번호 등록 시 `503`이면 코드가 유효할 때 다시 실행합니다. Swagger의 브라우저 수신 시험이 같은 번호로 열려 있으면 종료합니다. |
| 예약이나 변경이 미확인으로 표시됨 | **서버 상태 다시 확인**으로 결과를 확인합니다. 변경 전화가 미확인 상태에서 같은 시간의 변경 버튼이 다시 열리면 동일 시각을 한 번 더 확인할 수 있습니다. |
| 확정된 결과 화면에서 처음부터 다시 찍고 싶음 | 통화를 끝낸 뒤 **개발 도구 → 새 시연 처음부터 시작**을 사용합니다. 이 버튼은 촬영 화면을 처음 조건 선택으로 돌리고 기존 예약과 연결 한도는 보존합니다. |

외부 호출 없이 연습하려면 [MOCK 촬영 빌드와 절차](STATUS.md#2026-11-14-촬영용-pleos-ui-52--56)를 사용합니다. 운영 설정과 이전 검증 결과는 [Pleos 전화 시험 절차](PLEOS_PAIRED_PHONE_TEST.md)를 참고하세요.
