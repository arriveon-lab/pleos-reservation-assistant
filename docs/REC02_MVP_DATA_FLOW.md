# REC-02 MVP 데이터 흐름과 실제 연동 진입 조건

## 2026-11-10 최신 결정

Kakao 담당 C.L의 [답변2](https://devtalk.kakao.com/t/local-api/152647/2)를 확인했습니다. 동일 이용자 비교 세션 메모리는 종료 폐기·재사용 금지 조건으로 허용되며, 사용자 직접 전화 연결은 가능합니다. Kakao 상호/번호의 외부 전화·음성 업체 전달과 장기 예약 저장은 허용하지 않습니다. 장소 ID/URL 예외는 카카오맵 연결용입니다.

사용자 승인에 따라 예약용 매장 정보는 **성동구 OA-18655 공공데이터 우선**으로 개발합니다. 공공누리1유형의 저작권 이용허락과 실제 전화·개인정보·processor 보관/삭제 조건은 분리합니다. 모든 매장의 별도 동의를 개발 전제로 요구하지 않으며, 코드 준비는 #48·운영/팀 인수는 #11에서 이어갑니다.

[현재 사용 범위·저장/전달 계약·PR 답변 대조](PLACE_DATA_USE_MATRIX.md), [확인 근거](policy/rec02-evidence-2026-11-10.json)를 우선합니다. 아래 DATA-01–08/답변 대기/행 미수집 문구는 당시 단계의 이력이며 현행 정책 상태가 아닙니다. 기본 MOCK/LIVE 차단·#11 OPEN/#23 Draft를 유지합니다.


2026-11-10 통합 상태: #35의 [독립 품질 진단](REC10_SEOUL_PILOT_VALIDATION.md)과 #38의 [웹 상세정보 코드 준비](REC11_PLACE_DETAILS.md)는 main에 병합됐습니다. 아래 OA-18655를 다음 검증 후보로 둔 기록은 당시 단계입니다. 후속 진단/코드가 운영 공급 경로·저장/전화/AI 제공 조건의 최종 채택을 뜻하지 않으며 #11/PR #23은 OPEN/Draft입니다. 이번 main 반영에서는 문의/데이터를 재조회하지 않았고 새로운 정책 허용을 가정하지 않습니다.


결정일: 2026-11-09 KST. 담당 `tiemo0708`, [#11](https://github.com/arriveon-lab/pleos-reservation-assistant/issues/11), [Draft PR #23](https://github.com/arriveon-lab/pleos-reservation-assistant/pull/23). 사용자의 진행 지시에 따라 **현재 개발 경계**와 **다음 공급 경로 검증 순서**를 정합니다. 사업자의 별도 사용 허가·팀 인수·실제 예약 공급자 최종 채택을 대신하지 않습니다. 문서 변경이며 런타임 API/DB에는 적용하지 않았습니다.

## 오늘 확인한 근거

- 기존 [Kakao 문의](https://devtalk.kakao.com/t/local-api/152647)의 공개 본문과 공개 JSON 메타데이터를 읽었습니다. 확인 시 posts_count=1, reply_count=0, 보이는 글 번호는1이며 운영자 추가 답변은 확인되지 않았습니다. 새 글·재문의·수정·DM은 보내지 않았습니다.
- [Kakao FAQ](https://devtalk.kakao.com/t/faq-api/125610)와 [지도/로컬 담당 답변](https://devtalk.kakao.com/t/local-api/151263)은 실시간 이용과 결과/가공 데이터의 별도 저장 제한을 안내합니다. 이는 모든 검색을 답변 수신까지 중단하라는 의미로 해석하지 않습니다.
- [운영정책 제5조30항](https://developers.kakao.com/terms/ko/site-policies)의 정보 제공 제한과 대리인 기밀유지 예외를 함께 확인했습니다. 해당 예외가 우리 전화 공급자 구조와 Local의 보관 제한을 모두 해결한다는 답변은 없습니다.
- 대체 후보인 [성동구 일반음식점 인허가 데이터 OA-18655](https://data.seoul.go.kr/dataList/OA-18655/A/1/datasetView.do)는 공공누리1유형을 표시합니다. [제1유형 안내](https://www.kogl.or.kr/info/licenseType1.do)는 출처표시 하의 공유·변경·상업 이용을 설명합니다. 정확성/지속 제공 보장과 실제 전화 실행 승인은 별개입니다.

공개 문서/메타데이터만 확인했고 실제 장소 행·전화번호·Kakao 응답을 수집하지 않았습니다. [근거 요약](policy/rec02-evidence-2026-11-09.json)은 비밀 값과 장소 원문 없이 공유합니다.

## OA-18655의 다음 검증 순서

현재는 **공식 카탈로그/라이선스 확인**까지만 완료했습니다. 원시 행·파일/API 응답·연락처는 아직 가져오지 않았습니다.

1. **원본 확보 경로 확인:** 현재 문서의 파일 영역은 파일 없음으로 표시됩니다. API 명세/접근 방법·키/신청·요청 상한·추가 이용조건을 확인한 뒤 실행 계획을 만듭니다. 실제 파일이나 샘플을 가져오는 작업은 이 문서의 완료로 세지 않습니다.
2. **필드와 품질 확인:** 매장 식별자·상호·주소·전화·영업상태·수정일의 실제 제공 필드를 확인합니다. 전화 필드 존재/누락률·유효성·공용 대표번호 여부는 미검증입니다. 결측값을 다른 사업자/GPT로 자동 보충하지 않습니다.
3. **좌표 검증:** 안내된 좌표는 EPSG:5174이며 WGS84 위경도가 아닙니다. 재사용 가능한 변환 구현/테스트를 별도 검토하고, 단순 값 교환·범위 추정·상용 지오코딩 자동 호출을 하지 않습니다.
4. **시간/상태 검증:** 매일 갱신·3일 전 자료 안내가 있고 공개 열람본 간 표시 갱신일이 다릅니다. 조회 시각을 원 갱신일로 바꾸지 않고 실제 수신본의 버전/기준일을 확인합니다. 인허가상 영업 상태가 당일 운영/예약 가능을 보장하지 않습니다.
5. **저장·표시·제공 계약:** 기관/데이터명·원본 URL·라이선스·수신 버전·가공 여부를 기록합니다. 출처표시 문구와 개인정보 가능 필드의 최소 수집·보관/삭제·처리업체 범위를 #3/#4/#26과 검토합니다. 공공 라이선스를 녹음/AI 학습·임의 발신 승인으로 확대하지 않습니다.
6. **작은 시범과 채택:** 조건/품질 확인 뒤 허용된 출처만으로 성수·서울숲 후보를 평가합니다. 변환·중복/폐업·누락·UNKNOWN과 표시/삭제를 검사하고 팀 인수 후 실제 공급자와 구현 이슈를 확정합니다. 단순 카탈로그 열람으로 #11을 닫지 않습니다.

현재 출처표시 설계 예시는 `자료: 서울특별시 성동구 · 서울 열린데이터광장 OA-18655 · 공공누리 제1유형 / 수신본 기준일과 가공 내역 별도 표시`입니다. 실제 데이터 취득 시 제공 연도·원본 링크·수신본 라이선스로 확정하며 공공기관의 후원/제휴로 표현하지 않습니다.

## 직접 제공 매장 경로의 최소 입력

데이터를 직접 받을 수 있는 협의 매장이 있다면 다음을 비공개로 확인합니다. 이번에 매장에 연락하거나 동의를 받지 않았습니다.

- 제공자와 매장, 제공한 상호/주소/연락처·기준일, 원 출처와 증빙 참조
- 앱 표시·문의/예약·특정 음성 처리업체 전달·이력 보관의 목적별 범위
- 사용 기간·재확인·보관/삭제·철회·기존 예약 대조 조건
- 실제 통화 대상/시간·테스트 목적·횟수/비용 상한·AI 고지 등 #3의 별도 실행 조건

협의 가능 여부가 미확인인 상태에서 임의 매장 이름·번호를 선정하거나 데이터 제공/전화 동의를 받은 것으로 표시하지 않습니다. 증빙 원문·서명·실제 연락처는 공개 Git/fixture에 넣지 않습니다.
