- 첫 확장 실검색은 2곳, 다음 실검색은 3곳이었으나 주차·유아의자에 제삼자 자료만 있거나 근거가 부족했습니다. 성수 양식에 한해 2026-11-11 대조한 업체 공개 안내를 7일 동안 보완에 사용합니다. 같은 지점에는 상호·도로명주소가 일치할 때만 근거를 추가하며 검색에서 발견한 불가 보고는 덮지 않습니다.
- 스케줄 성수, 심퍼티쿠시 성수점, 제이드앤워터 성수 LCDC점의 주차·유아의자 안내를 확인했습니다. 건물 주차 지원과 발렛 조건을 표시하며 매장까지의 전체 무계단 동선은 미확인입니다.
- Java 460개 및 API 계약 스모크 통과. 최종 EC2 전화 시험 API에 성수·양식·주차·유아의자·무계단 조건을 전송해 스케줄 성수, 심퍼티쿠시 성수점, 제이드앤워터 성수 LCDC점 3곳과 각 출처를 확인했습니다. 주차·유아의자 3곳 모두 가능 근거 있음, 전체 무계단 동선은 3곳 모두 미확인입니다. 실제 발신·예약 제출은 0회입니다.

- 전화 시험 화면에 음식 취향 입력을 추가했습니다. 서버가 한식·양식·일식·중식·분식·아시아음식 표현을 해석하고, 제외·모호 표현을 구분합니다. 원 발화는 외부 모델에 전달하지 않습니다. 이 프로토타입은 음성 인식 대신 텍스트로 발화를 입력합니다.
- 요청한 음식 종류와 인용된 업종·메뉴 근거가 있는 후보만 필수 조건·후기 순위로 비교합니다. 구미 시험 목록은 음식 종류 검색을 우회하지 않습니다. 후보 부족 시 다른 음식으로 자동 대체하지 않습니다. 선택한 취향은 시험 예약과 승인 snapshot에 보존합니다.
- Java 457개, 전화 서비스·취향 전달 38개, API 계약 스모크와 웹추천 HTTP/CLI 검증을 통과했습니다. EC2 추천 JAR와 전화 API `web-phone-cuisine-20261111-2`에 배포했습니다.
- 성수 + `양식 먹고 싶어` + 주차·유아의자·무계단 조건으로 실제 웹검색 1회를 실행했습니다. 결과는 제이드앤워터 성수 LCDC점 1곳이며, [서울 공식 관광정보](https://stage-kr.visitseoul.net/restaurants/JadeWaterSeongsuLCDC/KOPhuefly)에서 지점·주소·서양식 분류·파스타 메뉴를 대조했습니다. 필수 조건 3개는 미확인이고 후기 자료는 수집되지 않았습니다. 3개 후보 확보나 조건 충족을 확인한 결과로 해석하지 않습니다.
- 후보 선택으로 만든 승인 대기 시험 예약에 양식 취향·주차·유아의자·무계단 조건이 보존됨을 EC2 화면에서 확인했습니다. 이 과정에서 발견한 기존 예약 카드의 `mobile` 변수 범위 오류를 수정하고 API 재시작·새로고침 후 정상 표시를 확인했습니다. 실제 발신·식당 예약 제출은 0회입니다.

## 2026-11-11 조건·후기 근거를 반영한 추천 순서

- 일반 웹검색과 구미 목록에서 모든 적격 후보를 평가한 뒤 최대 3곳을 선정하도록 변경했습니다. 필수 조건 충족 근거가 많은 순서, 관련 후기의 주의·상충 조건이 적은 순서, 긍정 언급 조건이 많은 순서로 비교하며 동점은 기존 근접 순서입니다. 일반 웹검색의 근접 순서는 모델에 요청한 순서이며 실제 거리 계산이 아닙니다.
- 방문자 후기만으로 조건을 확정하지 않습니다. 조건별 `reviewSignals`는 인용된 경험을 따로 표시하며 같은 조건의 리뷰를 여러 번 수집해도 가중치를 더하지 않습니다. 별점과 전체 리뷰 수는 사용하지 않습니다. 구미 목록에는 후기 자료가 없어 조건 근거와 거리로 비교합니다.
- 검색 지침과 시험 화면에 관련 후기의 긍정·주의 내용 및 추천 근거를 연결했습니다. Java `format verify`, 계약 스모크, 웹추천 HTTP 20건·CLI 5건, 전화 서비스 테스트 36개와 후기 카드 렌더링 검증을 통과했습니다.
- EC2 추천 JAR와 전화 API 화면(`web-phone-rank-20261111-1`)에 배포했습니다. 실제 시험 화면에서 구미의 주차·유아의자·무계단 조건으로 천생산아구찜 → 원조옛날국밥구미점 → 칼잡이남자 순서, 충족 근거 1/3·1/3·0/3, 영업시간·브레이크타임·주차 출처를 확인했습니다. 시험 API가 항상 주차를 조사하는 기존 동작도 유지합니다. 실제 후기 검색·전화 실행은 0회이며 후기 순위는 가상 자료 검증입니다.
